# Minerva NPC

Minerva NPC supports Icewind Dale: Enhanced Edition and the IWD1 campaign installed in EET with [IWD1_EET](https://github.com/The-Gate-Project/IWD1_EET).

For IWD1_EET, install Minerva NPC after IWD1_EET so the IWD campaign resources are available. The mod is intended for the IWD campaign and adds Minerva to Easthaven.
